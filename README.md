# Simple Personal Portfolio Website

A clean, single-page personal portfolio built using basic **HTML**, **CSS**, and **JS**.  
This project showcases sections like About Me, Skills, Projects, and Contact in a responsive layout.

## Features
- Fully responsive design
- Smooth scrolling navigation
- Sections for About, Skills, Projects, Resume, and Contact
- Simple and customizable structure

## Technologies Used
- HTML5
- CSS3
- JavaScript (optional for typing/text effects)

## How to Use
1. Clone or download this repository.
2. Open `index.html` in any browser.
3. Customize the content in HTML/CSS as needed.
